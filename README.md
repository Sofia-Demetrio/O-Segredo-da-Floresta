# Descrição do Projeto

O projeto "O Segredo da Floresta" é um jogo de aventura e investigação inspirado no folclore brasileiro.

A história acompanha um investigador que retorna à Reserva Florestal de Arandu em busca de respostas sobre o desaparecimento de sua irmã, Helena, e de uma equipe de pesquisadores ocorridos cinco anos antes.

Durante a jornada, o jogador enfrenta três figuras do folclore brasileiro:

* Curupira
* Iara
* Boitatá

Cada personagem apresenta um desafio diferente que deve ser superado para que a investigação continue.

Ao final da aventura, o jogador descobre a verdade por trás dos desaparecimentos e dos mistérios da floresta.

# Instruções para Executar

# Pré-requisitos

* Python 3 instalado.
* Biblioteca Pygame instalada.

# Instalação do Pygame

Abra o terminal e execute:

```bash
pip install pygame
```

# Execução

Na pasta do projeto, execute:

```bash
python main.py
```

# Controles

# Menus e Telas de História

* ENTER: avançar diálogos e telas.
* ESC: fechar o jogo (quando disponível).

# Minigame Curupira

* SETA ESQUERDA: mover personagem para a esquerda.
* SETA DIREITA: mover personagem para a direita.

Objetivo:
Desviar das bolas de fogo e alcançar o final da fase.

# Minigame Iara

* SETA ESQUERDA: mover personagem para a esquerda.
* SETA DIREITA: mover personagem para a direita.
* ESPAÇO: pular.

Objetivo:
Atravessar o rio utilizando as vitórias-régias sem cair na água.

# Minigame Boitatá

* Mouse: selecionar plataformas.

Objetivo:
Memorizar o caminho correto e atravessar a ponte sem errar.

# Desafio Final

* Teclado numérico: inserir um número de 1 a 100.
* ENTER: confirmar tentativa.

Objetivo:
Encontrar a árvore onde o ser escondido está localizado.

# Observações

Durante o desenvolvimento, o número sorteado para o desafio final é exibido no terminal para facilitar os testes.

Em alguns casos, o jogo pode encerrar inesperadamente devido a erros ainda não corrigidos. Caso isso aconteça, basta executá-lo novamente.
